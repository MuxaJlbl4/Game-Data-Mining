# Taz: Wanted Hint Video Exploit (HVE)

Taz: Wanted [HVE](https://pastebin.com/bWxXtJ7S) AutoHotKey 2 macro for PCSX2

## Requirements

- **Taz: Wanted** PlayStation 2 NTSC version (USA)
- **PCSX2** with overclocking: `Settings` -> `Emulation` -> `EE Cycle Rate` -> `300%`
- **PCSX2** keyboard bindings: `Settings` -> `Controllers` -> `Controller Port 1` -> `Shift + Click on Button` -> `Add Binding`
	- **`Start`** - **`Enter`**
	- **`Select`** - **`Backspace`**
	- **`✕`** - **`K`**
	- **`〇`** - **`L`**
	
## Usage

While moving in required direction, press:

- **`Num0`** - Full Spin HVE (FSHVE)
- **`Num1`** - Instant HVE (IHVE)

## Notes

- Using this macro is not acceptable by [speedrunning rules](https://www.speedrun.com/taz_wanted?h=Any&rules=game&x=02qv7jdy)
- IHVE can work incorrectly with moving to right
- Make sure CapsLock is turned off
