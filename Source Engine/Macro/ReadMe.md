# Source Engine Jump Macro
Script for exploiting jump glitches in **Half-Life 2** and **Portal**

### Usage
1. Edit script buttons with your controls and start `Source.ahk` script as **Administrator**
2. Make sure you have **CapsLock** turned off and keyboard layout is **English**
3. Hold the specified key in game to start:
	- `X` - [Accelerated Back Hopping](https://wiki.sourceruns.org/wiki/Accelerated_Back_Hopping)
	- `C` - [Object Wall Climbing](https://wiki.sourceruns.org/wiki/Wallclimbing)

### Notes
- Current velocity can be shown via `cl_showpos 1` command
- Sometimes releasing buttons doesn't stop macro - press it again to stop
- For [Object Wall Climbing](https://wiki.sourceruns.org/wiki/Wallclimbing) you should stand on pickable object looking down in front of the wall
