# Command & Conquer Generals (Zero Hour) Hotkeys

AutoHotKey 2 macro for [C&C Generals Game Code Project](https://github.com/TheSuperHackers/GeneralsGameCode):

- 🎞️ Binds **`NumEnter`** button to unlock render FPS separately from game logic FPS
- 🎥 Binds arrow keys camera scrolling to **`W`** **`A`** **`S`** **`D`** buttons
- 🧭 Binds numpad camera rotation to **`Q`** **`E`** buttons
- 🔄️ Unlocks original hotkeys behavior with **`Shift`** holding
- 🖱️ Prevents **`RMB`** holding to lock mouse scrolling feature

### Usage

Start `Generals.ahk` script as **Administrator**
